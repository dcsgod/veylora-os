# Supply-chain planner

Generated by Veylora OS from the `supply-chain` blueprint. It is a dependency-free Node.js (>= 20) application.

## Run

```
node server.mjs          # http://127.0.0.1:4310 (override with PORT)
node --test test/*.test.mjs
```

## Capabilities

| Area | Implementation |
| --- | --- |
| Data model | Products, locations, suppliers, inventory and purchase orders, validated with referential integrity checks (`src/domain.mjs`) |
| Ingestion | CSV import with row-level error reporting (`POST /api/ingest/{kind}`); see `fixtures/` for examples that include invalid rows |
| Forecasting | Moving average, exponential smoothing and Holt linear trend, with rolling-origin backtests (MAE/MAPE) |
| Replenishment | Continuous-review (s, Q) policy: normal-approximation safety stock, reorder point, EOQ, supplier minimum order quantity |
| Capacity | Warehouse volume utilisation with inbound projection and ok/warning/over status |
| Scenarios | Demand multiplier, lead-time change, service level and supplier disruption, compared with the baseline and saved |
| Persistence | JSON state written atomically to `data/runtime/state.json` |

## Limitations

- Demo data is **synthetic** and seeded (`src/data.mjs`); the UI shows a "Synthetic data" badge while it is in use.
- Forecasting methods are textbook baselines. They are not tuned production models, and their accuracy figures apply only to the data they were evaluated on.
- The replenishment policy assumes normally distributed weekly demand and treats each location independently. It does not do multi-echelon optimisation.
- The application has no authentication, so it binds to 127.0.0.1 only.
