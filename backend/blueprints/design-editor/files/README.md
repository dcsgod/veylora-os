# Design editor

Generated by Veylora OS from the `design-editor` blueprint. It is a dependency-free Node.js (>= 20) server with a browser editor. It is an original implementation of common layered-design-editor concepts and contains no third-party code, branding or assets.

## Run

```
node server.mjs          # http://127.0.0.1:4320 (override with PORT)
node --test test/*.test.mjs
```

## Features

- **Layers:** rectangles, ellipses, text, lines and embedded raster images.
- **Selection:** shift for multi-select, drag to move, corner handles to resize (shift keeps the aspect ratio), arrow keys to nudge (shift moves by 10).
- **Guides:** snap to canvas and layer edges and centres, with visible guides. Hold Alt to disable snapping.
- **Arrangement:** alignment (left, centre, right, top, middle, bottom) to the canvas or the selection; z-order; visibility and lock.
- **Editing:** a properties panel for geometry, colour, stroke, radius, opacity, rotation and typography. Undo/redo is bounded, and each drag merges into a single history step.
- **Templates and files:** four original templates. Designs save to the server and can be imported or exported as JSON.
- **Export:** SVG and PNG.

## Security model

Saved and imported designs are untrusted input. `src/serialize.mjs` accepts only known fields, hex colours and safe font names. Images must be embedded PNG, JPEG, GIF or WebP data URLs; remote URLs and SVG images are rejected, so a design cannot make network requests or inject script. SVG export XML-escapes all text.

## Limitations

- There is no grouping, gradients, path or pen tool, text wrapping, multi-page documents or real-time collaboration.
- Resizing works on the unrotated bounds of a layer.
- PNG export depends on the browser's SVG rasterisation, so fonts that are not installed fall back to system fonts.
